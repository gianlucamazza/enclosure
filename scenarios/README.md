Do not redistribute the pages or this pack as news, as a real status bulletin, or as a record of anything that occurred.

The primary site tells one authored story: home, status, notice, news. False pages occupy the same address as the honest ones, so a restoration puts the whole site back. Search still returns true background (explainers, Wikipedia on real past events). The copy does not name victims or describe how to cause the event.
